## Назначение
Автоматическое создание модульных тестов для верификации логики разрабатываемых в рамках курса ИИ-агентов и скриптов автоматизации.

## Инструкции для Агента
1. При генерации тестов использовать современные фикстуры и стандартные библиотеки (например, pytest для Python или базовые средства верификации для C++), исключая утечки ресурсов.
2. Проверять базовые граничные условия: передача пустых структур данных, некорректных форматов конфигурационных файлов и обработка таймаутов при имитации сетевых запросов.
3. Модульные тесты должны полностью покрывать методы парсинга локальных текстовых таблиц и проверок корректности промптов.
