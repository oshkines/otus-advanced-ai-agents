# Skill: Code Review

## Назначение
Автономный аудит качества кода учебных модулей на соответствие современным стандартам и правилам, описанным в проекте.

## Инструкции для Агента
1. При анализе кода обращать внимание на соответствие современным стандартам (исключение устаревших legacy-конструкций, использование безопасных смарт-указателей для C++).
2. Проверять структуру и форматирование файлов согласно правилам из `CLAUDE.md`.
3. Анализировать читаемость кода, давать рекомендации по оптимизации алгоритмов и рефакторингу сложных участков.
