# Отчет по Домашним заданиям №1 и №2: Настройка среды и GSD-пайплайна

**Ссылка на репозиторий:** [https://github.com/oshkines/otus-advanced-ai-agents]

## 1. Стек проекта и суть (из docs/about.md / README.md)
- **Суть:** AI Dev Orchestrator — отказоустойчивая модульная система автоматизации рутины и ИИ-анализа данных (C++20 управляющее ядро + Python воркеры).
- **Стек под Windows 11:** C++20, CMake, MSVC, SQLite3 (локальный кэш), Python 3.12.14, Playwright (Python-версия).
- **ИИ-модели:** Гибридная модель на базе DeepSeek-V3 (сортировка) и DeepSeek R1 / Gemini Pro (аналитика).

## 2. Реализация требований ДЗ-1 (Инфраструктура ИИ)
- **Инструкции агента:** В корне развернут `CLAUDE.md`, содержащий конвенции стиля кода C++/Python, команды сборки, тестов и линтеров.
- **Ограничение по путям (Permissions):** В файле `.clinerules` / `CLAUDE.md` настроен жесткий запрет на чтение и изменение файлов `.env`. 
  * *Как проверено:* Агенту Cline был дан прямой промпт на чтение `.env`. Агент выдал ошибку безопасности, заблокировав выполнение.
- **Три уровня прав:** Разрешены безопасные команды проверки (`py --version`), чтение секретов заблокировано на уровне ИИ-инструкций. Режим работы по умолчанию — `plan` (обоснование: предотвращает хаотичное изменение кода и экономит токены рассуждений).
- **Память между сессиями (Handoff):** Интегрированы handoff-файлы `docs/plan.md` (план спринта) и `docs/memory.md` (журнал решений). Агент успешно продолжает работу по чекбоксам после сброса контекста.

## 3. Реализация требований ДЗ-2 (Пайплайн разработки GSD)
- **Discovery Phase:** Пройден этап Discovery. Структура проекта полностью инициализирована: созданы архитектурный базис (`docs/architecture.md`), план (`docs/plan.md`), журнал памяти (`docs/memory.md`) и security-checklist.
- **Управление контекстом (Token Economy):** Проверено поведение при переполнении контекста в 11.2k токенов. Использован механизм `Start New Task` для автосжатия контекста и очистки логов ошибок API, что снизило потребление токенов до базовых файлов памяти.
- **Браузерная проверка и e2e-тест:** 
  * Создана локальная HTML-панель воркеров `src/status_panel.html`.
  * Написан сквозной e2e-тест `tests/browser_test.py` на базе Playwright.
  * Тест успешно запущен локально в изолированном окружении `.venv` в Windows 11. 
  * *Результат:* Тест выдал статус `GREEN / RESULT: PASS`, сгенерирован и сохранен финальный скриншот `docs/screenshots/green_e2e_test.png` (размер файла 44,7 КБ подтвержден ИИ-агентом).

## 4. Перечень учебных артефактов в репозитории:
- `CLAUDE.md` — главные инструкции для ИИ-агента.
- `config/orchestrator.json` — глубокий валидный конфигурационный JSON системы.
- `docs/architecture.md`, `docs/plan.md`, `docs/memory.md` — файлы управления контекстом GSD.
- `skills/code-review/SKILL.md` — навык аудита кода.
- `skills/test-generation/SKILL.md` — навык автоматического создания тестов.
- `src/status_panel.html` — целевой интерфейс для браузерного теста.
- `tests/browser_test.py` — e2e-тест интерфейса на Playwright.
- `.gitignore` — исключение папки `.venv` и бинарников из фиксации Git.
