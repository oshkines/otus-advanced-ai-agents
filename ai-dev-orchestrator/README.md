# AI Dev Orchestrator

Учебный проект для настройки AI-ориентированной среды разработки в рамках курса OTUS "ИИ-агенты".

## 📊 Результаты 1-го Модуля (Выбор стека и обоснование)

1. **Тип Агента и Среда:** Выбран IDE-агент на базе **VS Code** с расширением **Cline** и параллельным развертыванием **DeepSeek Harness**. Это обеспечивает максимальный визуальный контроль изменений в коде по сравнению с CLI-агентами (Claude Code).
2. **Выбор Экосистемы LLM:** 
   - *Основная модель:* Облачный **DeepSeek** по официальным API-токенам (максимальное качество рассуждений, доступность в РФ без геоблокировок в отличие от моделей Anthropic).
   - *Локальная модель:* Локальный **DeepSeek-R1 (14b)** через Ollama (используется как резервная копия для экономии трафика токенов на простых задачах).
3. **Борьба с рисками (Галлюцинации и потеря контекста):**
   - Интегрирован открытый стандарт **MCP**. Подключен сервер **context7** от Upstash для динамической подкачки актуальной технической документации в контекстное окно.
   - Создан файл **CLAUDE.md** со строгими архитектурными и поведенческими ограничениями для моделей.

   ## 🛠️ Настройка SKILLs и команд /command

1. **Доступные SKILLs (Инструменты разработки):**
   - **Code-Review & Валидация:** Реализовано через связку модели `deepseek-reasoner` и инструкций в `CLAUDE.md`. Агент автоматически проводит аудит C++20 и 1С кода на соответствие стандартам производительности и архитектурным ограничениям проекта.
   - **Актуализация документации (MCP):** Подключен локальный скилл через MCP-сервер `context7-mcp` для динамического анализа синтаксиса внешних библиотек без галлюцинаций.
2. **Управление через команды:**
   - Взаимодействие с агентом и вызов встроенных скиллов тестирования и анализа кода осуществляется через стандартные интерактивные промпты и встроенные команды расширения Cline (`/help` и контекстные вызовы инструментов).
   
	## ⌨️ Конфигурация кастомных команд ассистента

Для вызова заложенных навыков в среде Cline настроены следующие кастомные алиасы команд:

*   **`/review`** — Запуск автономного аудита измененных учебных файлов. Команда активирует навык `skills/code-review/SKILL.md`, принудительно проверяя код на соответствие стандартам оформления и ограничениям, описанным в `CLAUDE.md`.
*   **`/testgen`** — Вызов генератора модульных тестов. Команда обращается к навыку `skills/test-generation/SKILL.md`, анализирует структуру созданного скрипта или модуля и автоматически формирует тестовые сценарии.

*Примечание: Вызов команд осуществляется в интерактивном чате Cline путем ввода соответствующего слэш-тега перед текстом задачи.*
