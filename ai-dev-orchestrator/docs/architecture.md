# Архитектура: AI Dev Orchestrator (Windows Native)

## Компоненты системы
1. **C++20 Core (Управляющий):** Консольное приложение, собирается через CMake + MSVC 2022. Читает конфиг `config/orchestrator.json`. Запускает Python-воркеры по расписанию.
2. **Python 3.11+ Workers (Исполнители):** Скрипты в папке `agents/`. Общаются с ядром через JSON в `stdout`.
3. **БД SQLite3:** Локальный кэш ID сообщений/писем, чтобы не слать дубли и экономить ИИ-токены.
