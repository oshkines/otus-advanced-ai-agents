# DESIGN.md — AI Dev Orchestrator & Smart Assistant

## 1. Atmosphere
*   **Прилагательные:** Сдержанный (Frugal), Монолитный, Отказоустойчивый.
*   **Плотность интерфейса (Density):** Высокая (Compact) для разработчиков и инженеров.
*   **Вариативность (Variance):** Низкая, строго стандартизированные UI-компоненты.
*   **Анимация (Motion):** Минимальная, функциональная (микро-взаимодействия загрузки и успеха).

## 2. Colors
Палитра построена по правилу 60-30-10 на базе темной инженерной темы (контрастность проверена ≥ 4.5:1 через Coolors).
*   `--color-canvas`: `#0A0E17` — Глубокий темный фон (60% площади экрана).
*   `--color-surface`: `#161B22` — Фоновые поверхности карточек, списков и панелей.
*   `--color-border`: `#30363D` — Разделительные линии и границы.
*   `--color-ink`: `#C9D1D9` — Основной текст (безопасный светло-серый, 30% площади).
*   `--color-muted`: `#8B949E` — Вторичный текст, таймстампы, метаданные.
*   `--color-primary`: `#58A6FF` — Синий акцент для главных CTA-кнопок и ссылок.
*   `--color-success`: `#238636` — Зеленый маркер для валидных алертов, вакансий и успешных покупок билетов (10% акцентов).
*   `--color-warning`: `#D29922` — Оранжевый маркер PENDING-классификации и предупреждений.

## 3. Typography
*   **Шрифты:** Заголовки и код — `JetBrains Mono` / `SF Mono` (системный моноширинный). Основной текст — `Inter` / системный Sans-Serif.
*   **Шкала (Scale):**
    *   `H1` (Название дашборда): 24px / Line-height: 32px (Bold)
    *   `H2` (Заголовки секций): 18px / Line-height: 24px (Semi-Bold)
    *   `Body` (Основной текст/логи): 14px / Line-height: 20px (Regular)
    *   `Caption` (Метаданные/таймстампы): 12px / Line-height: 16px (Regular)

## 4. Spacing & Grid
*   **Базовая сетка:** 8-пиксельный шаг (`8px`, `16px`, `24px`, `32px`).
*   **Макет:** Bento-Grid (3 столбца на Desktop, 1 столбец на Mobile) для одновременного вывода логов модулей (Почта, Вакансии, РЖД).
*   **Радиус скругления (Border Radius):** `6px` для кнопок и `12px` для bento-карточек (строгий инженерный стиль).

## 5. Components & UX-Patterns
### Кнопки (CTA)
*   **Главная (Primary):** Заливка `--color-primary`, текст белый. Высота `40px` (Соответствие закону Фиттса).
*   **Действие (Action/Success):** Заливка `--color-success` (например, "Купить билет РЖД").
*   **Состояния:** Default ➔ Hover (яркость +10%) ➔ Active (scale 0.98) ➔ Disabled (opacity 0.4).

### Карточка оповещения (Alert Card)
*   Группировка элементов по закону Миллера: Источник (Почта/ТГ/РЖД) ➔ Суть (Заголовок/Статус) ➔ Краткое саммари (от ИИ) ➔ Метаданные (Время).

## 6. States (5 обязательных состояний по Нильсену)
1.  **Empty (Пусто):** Нет новых писем / билетов. Выводится текст: "Система в режиме ожидания. Новых событий не обнаружено".
2.  **Loading (Загрузка):** Асинхронный опрос IMAP/API. Показывается неблокирующий индификатор (Shimmer-эффект на карточке).
3.  **Partial (Частичные данные):** Письмо скачано частично (только заголовок + 200 символов) для ИИ-классификации.
4.  **Error (Ошибка сети/РКН):** Красная плашка `--color-warning`. Текст понятным языком: "Mail.ru недоступен (Таймаут соединения). Авто-переподключение через 30с". (Сохраняется кнопка "Повторить").
5.  **Success (Успех):** Зеленый маркер, мгновенное появление ответа.

## 7. AI UX & Optimistic UI
*   **Скрытие задержек (Optimistic UI):** При клике на "Запросить полное письмо" или "Подтвердить покупку билета РЖД" интерфейс мгновенно переходит в состояние ожидания с анимацией шагов агента ("Выкачиваю тело...", "Генерирую саммари через DeepSeek-R1..."). Кнопка блокируется, предотвращая повторные клики (Закон Хика).
*   **Стриминг (Streaming):** Генерация саммари от DeepSeek выводится посимвольно (токен-за-токеном) в реальном времени, снижая когнитивное ожидание пользователя.

## 8. Motion & Micro-interactions
*   Переходы между табами bento-сетки: `duration: 200ms`, `easing: cubic-bezier(0.4, 0, 0.2, 1)`.
*   Поддержка `reduced-motion` для экономии ресурсов процессора в Windows 11.

## 9. References

## 10. Don'ts (Запрещенные клише)
*   Запрещено использовать градиенты на карточках (размывают фокус инженера).
*   Запрещено использовать случайные эмодзи в качестве иконок (смешивание стилей). Использовать только системный набор линейных иконок.
*   Запрещено скрывать контекст ошибки за безликим "Произошла ошибка" (всегда выводить лог таймаута сокета).
